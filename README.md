# Apple Watch 高血压通知 · 中文智能体指南

让你习惯使用的智能体陪你核对手表是否支持高血压通知，在配对 iPhone 上找到设置，并记录实际结果。全程可以只用文字对话，无需安装软件或连接 Mac。

## 第一次使用

**只需要一个文件，叫 `SKILL.md`。** 它是一份写给智能体的文字指南。手机和电脑都可以用，最简单的方式是复制粘贴。

### 方法一 · 复制到聊天框（推荐）

1. [点这里打开技能全文](https://raw.githubusercontent.com/putinc/apple-watch-health-guide/main/SKILL.md)。手机上长按文字，选「全选 → 复制」；电脑上可以直接全选、复制。
2. 打开平时使用的智能体，例如豆包或 DeepSeek，新建一个对话，把全文粘贴进去。
3. 在末尾另起一行，加上下面这句话，一起发送。

> 请按这份指南，一次一步带我检查我的 Apple Watch 能否开启高血压通知。先问我需要提供哪些设备信息。

智能体会先询问手表和 iPhone 型号、系统版本及使用地区。等它引导你打开「健康核对清单」后，告诉它屏幕上显示的是「设置」「已开启」还是「不可用」，就能继续。若苹果在你的机型或地区未提供入口，这份指南可以帮你核对原因，无法解锁地区限制。

### 方法二 · 把文件发给智能体

1. 打开 [SKILL.md 文件页](SKILL.md)，点文件右上方的下载按钮（Download raw file），保存到电脑的「下载」文件夹即可。
2. 打开智能体的新对话，通过附件按钮添加这个文件，或把文件拖进聊天框。
3. 发送上面的那句话。如果客户端无法读取附件，使用方法一即可。

### 方法三 · 在 Codex 或 WorkBuddy 中打开项目

如果你的客户端可以打开本地文件夹，在本仓库首页点绿色 **Code → Download ZIP**。解压，打开里面能看到 `SKILL.md` 的文件夹，然后发送：

> 请读取这个文件夹里的 SKILL.md，按它一步步带我检查 Apple Watch 的高血压通知。

以上方式都可以重复使用。同一份文字也可交给其他聊天助手；各客户端的文件读取与联网能力有所不同，尚未逐平台实测。

**只想自己查看**，可在配对 iPhone 打开「健康 → 头像 → 健康核对清单」，查看「高血压通知」当前状态。地区和机型限制见[苹果功能可用性表](https://www.apple.com/watchos/feature-availability/)。

## 项目从何而来

维护者曾借助星辰智能体（TeleAgent）进行一次国行 Apple Watch 实验，并亲自确认高血压通知完成设置。公开版整理了可跨平台复用的问答、官方设置指引和一份脱敏案例。原实验涉及第三方配件认证身份；本仓库不提供其提取、复用或地区解锁脚本。参见[实验记录与证据边界](cases/2026-11-21.md)。

## 分享你的结果

可以开一个 Issue，注明日期、设备型号、系统版本、当前使用地区、开始时的界面文字、最终界面文字和待核实事项。型号或结果不清楚就写「未知」。只提交这些文字即可，保留设备名、序列号、账户和个人健康信息的隐私。
